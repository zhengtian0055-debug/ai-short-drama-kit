# AI 短剧生产工作流套件

一套可以照着跑通的竖屏 AI 写实短剧生产流程，加一集 60 秒的完整制作包。

不是"提示词收藏"，是一份**能复现的流程**：资产先锁定 → 镜头发安全区 → 一镜一生成 → 配音反推剪辑 → 数据回流。

## 快速开始

1. **先做资产，不做视频。** 用 `prompts/EP01-即梦提示词.md` 里的四张角色卡出图，出到"三个角度遮住背景还认得是同一个人"为止。
2. **出首帧图。** 18 个镜头各出一张首帧，按 `S01.jpg … S18.jpg` 命名。
3. **只先动 6 个关键镜头**：S02 / S05 / S07 / S12 / S17 / S18。这 6 镜成了，整集就成了。
4. **图生视频，单镜 3–5 秒**，同镜跑 2–4 次挑最好的；连崩两次就换镜头设计，别死磕。
5. **先配音再剪辑**，用配音长度反推剪辑点。
6. **导出** 1080×1920 / 30fps / H.264。

## 三条核心原则

- **预防 > 补救。** 崩脸不是靠后期修，是靠角色卡 + 首帧图提前锁死。
- **一镜一生成。** 绝不让模型一次出 15 秒以上的成片。
- **首尾帧接力。** 同场景同机位时，上一镜的尾帧就是下一镜的首帧，剪起来才不跳。

## 镜头安全清单

**安全**：静坐对话近景、特写手/物件、背影行走、开门、起身、侧脸、俯拍桌面、缓慢推镜。

**高危**：正脸走路、多人快速对话交接、精细手部动作、打斗、镜面反射、画面里的真实文字、儿童与宠物、人物互相递东西。

改写方式：正脸走路 → 背影/侧影；精细手部 → 物件特写 + 画外音；画面文字 → 生成空白，后期贴字。

## 合规

- AI 生成内容按平台要求标注"AI 生成"。
- 人物形象与配音音色不得与真实明星、真人声音高度相似。
- 改编他人作品需先取得授权；上线涉及备案。
- 免费/低价额度素材可能带水印，商用前确认授权范围。
